# テキスト解析型タスク管理アプリ

## 概要
入力した文章を解析し、自動でタスクを抽出・生成するWebアプリケーションです。  
ユーザーが日常的に入力する自然文からタスクを整理することで、効率的なタスク管理を実現することを目的としています。

---

## 背景
日常生活や業務の中で、「やるべきこと」を文章としてメモすることは多いですが、そこからタスクを整理するのは手間がかかります。  
そこで、自然言語処理を活用し、文章からタスクを自動生成することで、タスク管理の効率化を図りました。

## 主な機能

- テキスト入力
- テキスト解析（自然言語処理）
- タスクの自動生成
- タスクリスト表示

---

## 工夫した点

- 外部API（Google Cloud Natural Language API）を利用し、文章から意味のある情報を抽出
- フロントエンドとバックエンドを分離した構成で実装
- ユーザーが直感的に操作できるシンプルなUI設計
